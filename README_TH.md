# Eldoria 0.4-modern — โค้ดและชุดพร้อมนำขึ้นเว็บ

อ่าน AI_HANDOFF_TH.md ก่อนเริ่มงาน มีรายละเอียดไฟล์ เหตุผล วิธี build/test/เซ็นและ deploy ครบ
อ่าน HANDOFF.md สำหรับงานค้างเกมอื่นและกฎเดิม

## ใช้งานทันที
APK ที่ให้ผู้ใช้คือ Eldoria-0.4-modern.apk ติดตั้งทับแอป Eldoria ทดสอบแก้เด้ง 0.3 ได้
ใน ZIP ใช้ชื่อ Eldoria-modern.apk เพื่อให้ apk.html อ้างไฟล์ถูกต้อง
ภาพตัวอย่างจริงและผลทดสอบอยู่ verification/

## รวมอะไรบ้าง
- source/ ฉบับครบล่าสุด รวมแก้เด้ง 0.2 การตี/กลิ้ง 0.3 และภาพ 0.4
- index.* ชุด export เว็บพร้อมใช้ รุ่น 0.4-modern จาก Godot 4.7.2
- apk.html + Eldoria-modern.apk คู่กัน สำหรับหน้าโหลดรุ่นใหม่
- HANDOFF.md และ AI_HANDOFF_TH.md
- verification/ ภาพก่อน/หลังและผลทดสอบ รวม benchmark พร้อมข้อจำกัด

## สถานะสำคัญ
ยังไม่ได้ขึ้น GitHub หรือ GitHub Pages จริง เพราะการเขียน repo chatchai2537/eldoria-godot ถูกปฏิเสธ 403
AI ตัวถัดไปต้องได้สิทธิ์เขียนก่อน และตรวจ main ล่าสุดเพื่อไม่ทับงานคนอื่น
ห้ามอัปโหลด ZIP เป็นไฟล์เดียวแล้วคิดว่าเกมอัปเดต ต้องแตกและนำ source/index.* กับ apk.html/APK ลงตำแหน่งที่ระบุในใบงาน
ไม่มี .godot หรือกุญแจเซ็นอยู่ใน ZIP; วิธีรับคีย์ทดสอบเดิมอยู่ในใบงานแยกจาก repo
ยังไม่ได้เทส 0.4 บนมือถือเจ้าของ; โครงโมเดลหลักยังเป็น KayKit 3D เดิมที่ปรับวัสดุ/สัดส่วน ไม่ใช่โมเดล photorealistic ใหม่
