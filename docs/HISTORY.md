## 2. กฎที่เจ้าของสั่งไว้ (ห้ามละเมิด)
1. **เอาแค่ "ระบบ" จากเกม 2D ไม่เอาโค้ด**: เกม 2D มีไฟล์แก้ทับกันเป็นร้อยๆ ไฟล์ (fix1...fix136+) **ห้ามคัดลอกโค้ดหรือโครงสร้างไฟล์แบบนั้นมา** ให้เขียนใหม่สะอาดๆ ใน Godot · ดูเกม 2D เพื่อรู้ว่าระบบทำงานยังไง ชื่อร้าน NPC บทพูด ราคา เท่านั้น
   - ค่าตัวเลขต้องดู **ไฟล์ fix ตัวหลังสุด** ที่ทับระบบนั้น ไม่ใช่ไฟล์ core แรกๆ · **สิ่งที่เจ้าของสั่งเปลี่ยนแล้ว ถือเป็นค่าสุดท้ายเสมอ** (ดูหัวข้อ 6)
2. **ภาพต้องสมจริง ไม่ใช่บล็อก** (ตอนนี้ใช้โมเดล KayKit เป็นตัวชั่วคราว ดูหัวข้อ 7)
3. **เพิ่มของใหม่โดยไม่รื้อระบบเดิม** แก้เฉพาะจุดที่จำเป็น
4. **ทำเสร็จต้องขึ้นเว็บทุกครั้ง** (export แล้ว push ตามหัวข้อ 4) ไม่ต้องรอให้เจ้าของสั่ง "อัพ"
5. เจ้าของทดสอบบน **มือถือ** เป็นหลัก ของใหม่ต้องใช้บนจอสัมผัสได้ด้วย
6. **ห้ามใช้ภาพที่ AI วาด (ChatGPT) กับตัวละครหรือมอนสเตอร์** ตัวละครใช้โมเดล 3D
7. ทำงานเสร็จให้สรุปเป็นภาษาไทยสั้นๆ ว่าเพิ่มอะไร และให้ไปลองตรงไหน

## 4. วิธี build และขึ้นเว็บ
```bash
# export เว็บ (ต้องมี export templates 4.7.2)
godot --headless --path source --export-release "Web" ../build/web/index.html
# คัดลอก index.* จาก build/web ไปไว้ที่ root ของ repo แล้ว commit + push ที่ main
# GitHub Pages อัปเดตเองภายใน 1-2 นาที
```
- ทดสอบ headless ถ่ายภาพหน้าจอ: `godot --path source -- --shot=ชื่อ,เวลา(0-1),หมุนกล้อง,ระยะกล้อง,ช่องX,ช่องY[,โหมด]`
  - โหมด: `shop:gear` เปิดร้าน · `talk:0` คุยกับ NPC ตัวที่ 0 · `fight:600` วางสไลม์แล้วสั่งตีอัตโนมัติ 600 เฟรม (พิมพ์บรรทัด `STATS ...`)
  - ช่อง X ติดลบ = ทุ่งหญ้า (เช่น `-12,16`) · ภาพเก็บที่ `user://ชื่อ.png`
- ไฟล์ .wasm ประมาณ 40MB · .pck ประมาณ 7MB (GitHub รับได้ ไม่เกิน 100MB ต่อไฟล์)
